Visage Native (`@epoch32/visage/native`) provides a unified, type-safe IPC (Inter-Process Communication) bridge between your Visage web UI and a lightweight native desktop host written in Zig. Instead of shipping a 150MB+ Chromium runtime like Electron, Visage pairs with native OS web engines (WebView2 on Windows, WKWebView on macOS, and WebKitGTK on Linux) to produce executables under 10MB that start instantaneously.

## Detecting Native Host (isNativeApp)

Use `isNativeApp()` to conditionally render native desktop controls, title bars, or file system access buttons:

<CodeBlock
  filename="components/TitleBar.tsx"
  lang="tsx"
  code={`import { isNativeApp, native } from "@epoch32/visage/native";
import { Show } from "@epoch32/visage";

export function TitleBar() {
  return (
    <Show when={isNativeApp()}>
      <header class="h-8 bg-zinc-900 flex justify-between items-center px-3 select-none">
        <span class="text-xs text-zinc-400">Visage Studio</span>
        <div class="flex gap-2">
          <button onClick={() => native.minimize()} class="hover:bg-zinc-800 px-2 text-xs">
            _
          </button>
          <button onClick={() => native.maximize()} class="hover:bg-zinc-800 px-2 text-xs">
            [ ]
          </button>
          <button onClick={() => native.close()} class="hover:bg-red-600 px-2 text-xs">
            x
          </button>
        </div>
      </header>
    </Show>
  );
}`}
/>

## Calling Native Commands (native.invoke)

Use `native.invoke<T>(command, payload)` to execute native functions on the Zig backend (e.g., reading local files, querying hardware specs, or opening OS dialogs):

<CodeBlock
  filename="lib/systemInfo.ts"
  lang="ts"
  code={`import { native } from "@epoch32/visage/native";

interface SystemInfo {
  os: "windows" | "macos" | "linux";
  cpuCores: number;
  memoryGb: number;
  homeDir: string;
}

export async function fetchSystemInfo(): Promise<SystemInfo> {
  const info = await native.invoke<SystemInfo>("getSystemInfo", {
    includeMemory: true,
  });
  return info;
}

export async function openNativeFileDialog(): Promise<string | null> {
  const filePath = await native.invoke<string | null>("dialog:openFile", {
    filter: ["*.png", "*.jpg", "*.webp"],
  });
  return filePath;
}`}
/>

## Listening for Native Events (native.on)

Subscribe to asynchronous events pushed from the host (such as global hotkeys, file drop events, system sleep notifications, or USB plug events):

<CodeBlock
  filename="components/HotkeyListener.tsx"
  lang="tsx"
  code={`import { onCleanup } from "@epoch32/visage";
import { native } from "@epoch32/visage/native";

export function HotkeyListener() {
  // Listen for global shortcut registered in Zig
  const unsubscribe = native.on("hotkey:save", (payload) => {
    console.log("Global save triggered from host:", payload);
    saveCurrentProject();
  });

  // Clean up listener when component unmounts
  onCleanup(() => {
    unsubscribe();
  });

  return null;
}`}
/>

## API Reference

### `native.invoke()`

Sends a command with an optional payload to the native Zig desktop host. Resolves when the host responds or falls back to browser mock mode in non-native environments.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function invoke<T = any>(command: string, payload?: any): Promise<T>`}
/>

#### Parameters
- `command` (`string`): The IPC command name registered in the Zig host handler.
- `payload` (`any`, optional): Data passed to the host command handler.

#### Returns
- `Promise<T>`: Resolves with the payload response returned by the host.

<hr className="api-divider" />

### `native.on()`

Subscribes to asynchronous native events broadcast from the Zig desktop host. Automatically unbinds when the returned cleanup disposal function is invoked or when the component scope tears down.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function on(event: string, callback: (payload: any) => void): () => void`}
/>

#### Parameters
- `event` (`string`): The event channel name emitted by the native application.
- `callback` (`(payload: any) => void`): Listener invoked whenever the host pushes an event on this channel.

#### Returns
- `() => void`: Unsubscribe cleanup function.

<hr className="api-divider" />

### `native.isNativeApp()`

Returns `true` when running inside a supported native desktop webview environment (WebView2 on Windows, WKWebView on macOS, WebKitGTK on Linux), or `false` in standard web browsers.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function isNativeApp(): boolean`}
/>

#### Returns
- `boolean`: `true` if executing within a native desktop shell, `false` otherwise.

<hr className="api-divider" />

### `native.close()` / `minimize()` / `maximize()`

Convenience functions that invoke `"window:close"`, `"window:minimize"`, and `"window:maximize"` on the host window manager for custom frameless titlebars.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function close(): Promise<void>
function minimize(): Promise<void>
function maximize(): Promise<void>`}
/>

#### Returns
- `Promise<void>`: Resolves once the window state change command is dispatched.
