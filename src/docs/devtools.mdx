## Mounting the DevTools (&lt;VisageDevTools&gt;)

In development, the Visage Vite plugin can auto-inject DevTools into your HTML shell. Alternatively, you can render `<VisageDevTools />` explicitly in your root component:

<CodeBlock
  filename="src/main.tsx"
  lang="tsx"
  code={`import { render, createSignal } from "@epoch32/visage";
import { VisageDevTools } from "@epoch32/visage/devtools";

function App() {
  const [count, setCount] = createSignal(0, { name: "app.counter" });

  return (
    <div>
      <h1>Visage Application</h1>
      <button onClick={() => setCount((c) => c + 1)}>Increment</button>

      {/* Floating launcher badge in bottom-right corner */}
      {import.meta.env.DEV && <VisageDevTools position="bottom-right" />}
    </div>
  );
}

render(() => <App />, document.getElementById("app")!);`}
/>

## Signals & Stores Inspector

The **Signals** tab lists all registered signals and deep stores in your application:
- **Live Values**: Inspect scalar numbers, strings, and complex nested store objects.
- **Dependency Count**: See exactly how many DOM elements or computed expressions subscribe to each signal.
- **Manual Mutation**: Edit signal values directly in the DevTools drawer to test UI edge cases on the fly.

## Live DAG Graph Visualization

The **DAG Graph** tab renders an interactive SVG diagram of the reactive network:
- **Nodes**: Round nodes represent signals (writable), hexagonal nodes represent computed derivations, and diamond nodes represent effects or DOM text nodes.
- **Live Pulses**: Nodes flash brightly when updated, letting you identify unnecessary updates or circular dependency chains instantly.
- **Topological Sorting**: Visualizes dependency depth from root state to UI outputs.

## Queries & RPC Network Timeline

Connect your `QueryClient` to track async cache status:

<CodeBlock
  filename="src/query-setup.ts"
  lang="ts"
  code={`import { QueryClient } from "@epoch32/visage/query";
import { connectDevTools } from "@epoch32/visage/devtools";

export const queryClient = new QueryClient();

// Connect to DevTools hub in development:
if (import.meta.env.DEV) {
  connectDevTools(queryClient);
}`}
/>

The **Queries** and **RPC** tabs display:
- Cache key states (`fresh`, `stale`, `fetching`)
- Request duration metrics
- RPC batch payload inspections
- Manual "Refetch" and "Invalidate" triggers

## DOM Element Highlighter

Hovering over a signal or reactive node in the DevTools panel highlights the associated physical DOM element on the page using a bright overlay, confirming exactly which DOM nodes update when that signal changes.
