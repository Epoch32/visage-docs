Visage provides a first-class, zero-build `html` tagged template literal engine. You can write reactive, fine-grained components in pure JavaScript or TypeScript without needing Babel, SWC, or a JSX compiler.

## The html Tagged Template

Import `html` directly from `@epoch32/visage/template`:

<CodeBlock
  filename="Counter.ts"
  lang="ts"
  code={`import { html } from "@epoch32/visage/template";
import { createSignal } from "@epoch32/visage";

export function Counter() {
  const [count, setCount] = createSignal(0);

  return html\`
    <button onClick=\${() => setCount(c => c + 1)}>
      Clicked \${count} times
    </button>
  \`;
}`}
/>

## Fine-Grained Interpolation

Just like Visage JSX, template literals compile to native `<template>` elements. Dynamic expressions `${count}` bind directly to precise DOM text nodes or attributes without Virtual DOM diffing.

<CodeBlock
  filename="DynamicAttributes.ts"
  lang="ts"
  code={`import { html } from "@epoch32/visage/template";
import { createSignal } from "@epoch32/visage";

export function UserBadge() {
  const [active, setActive] = createSignal(true);

  return html\`
    <div class=\${() => (active() ? "badge active" : "badge")}>
      <span>Status: \${() => (active() ? "Online" : "Offline")}</span>
    </div>
  \`;
}`}
/>

## When to Use html vs JSX

- **Buildless Environments**: Prototyping directly in browsers via ES modules or CDN.
- **Micro-Frontends**: Embedding small reactive widgets inside legacy non-build apps.
- **SSR Script Templates**: Generating reactive templates on the fly in Cloudflare Workers or server scripts.
