Visage includes a high-performance SVG chart engine (`visage/charts`). Because Visage bypasses Virtual DOM diffing, SVG path strings, coordinate transformations, and hover cursors react directly to signal updates with smooth 60fps responsiveness.

## Line Charts (&lt;Line&gt;)

Compose a reactive line chart using `<Chart>`, `<Line>`, `<XAxis>`, and `<YAxis>`:

<CodeBlock
  filename="LineChartExample.tsx"
  lang="tsx"
  code={`import {
  Chart,
  Line,
  XAxis,
  YAxis,
  CartesianGrid,
  Tooltip,
} from "@epoch32/visage/charts";

const telemetryData = [
  { time: "10:00", requests: 120 },
  { time: "10:05", requests: 240 },
  { time: "10:10", requests: 310 },
  { time: "10:15", requests: 190 },
  { time: "10:20", requests: 450 },
  { time: "10:25", requests: 380 },
];

export function ServerRequestsChart() {
  return (
    <Chart data={telemetryData} xKey="time" yKey="requests" width={600} height={300}>
      <CartesianGrid strokeDasharray="3 3" />
      <XAxis />
      <YAxis />
      <Tooltip />
      <Line stroke="#ec4899" strokeWidth={3} smooth dot />
    </Chart>
  );
}`}
/>

Props for `<Line>`:
- `stroke`: Color of the line path (e.g. `"#ec4899"`).
- `strokeWidth`: Stroke thickness in pixels (default `2`).
- `smooth`: Enables monotonic cubic Bezier spline smoothing.
- `dot`: Renders interactive data anchor circles on data points.

## Area Charts (&lt;Area&gt;)

`<Area>` closes the path polygon along the bottom baseline for filled area visualizations:

<CodeBlock
  filename="AreaChartExample.tsx"
  lang="tsx"
  code={`import { Chart, Area, XAxis, YAxis, CartesianGrid } from "@epoch32/visage/charts";

export function BandwidthChart({ data }: { data: any[] }) {
  return (
    <Chart data={data} xKey="date" yKey="gigabytes" width={600} height={260}>
      <CartesianGrid />
      <XAxis />
      <YAxis />
      <Area
        fill="#a855f7"
        fillOpacity={0.25}
        stroke="#a855f7"
        smooth
      />
    </Chart>
  );
}`}
/>

## Pie & Donut Charts (&lt;Pie&gt;)

`<Pie>` computes radial arc angles and path geometries:

<CodeBlock
  filename="PieChartExample.tsx"
  lang="tsx"
  code={`import { Chart, Pie, Tooltip, Legend } from "@epoch32/visage/charts";

const storageData = [
  { type: "Documents", size: 40 },
  { type: "Media", size: 35 },
  { type: "System", size: 15 },
  { type: "Free Space", size: 10 },
];

export function StorageDistribution() {
  return (
    <Chart data={storageData} width={350} height={350}>
      <Pie
        valueKey="size"
        labelKey="type"
        donut
        innerRadius={60}
        outerRadius={110}
        padAngle={0.03}
        colors={["#ec4899", "#a855f7", "#3b82f6", "#10b981"]}
      />
      <Tooltip />
      <Legend />
    </Chart>
  );
}`}
/>

## Axes, Grid & Cursor Tooltips

Visage chart sub-components compose cleanly:
- `<XAxis />` and `<YAxis />`: Format ticks, labels, and coordinate bounds automatically.
- `<CartesianGrid />`: Draws subtle grid lines across horizontal and vertical tick divisions.
- `<Cursor />`: Renders an interactive vertical scrub line tracking the mouse cursor position.
- `<Tooltip />`: Floating reactive popup displaying current x/y key values.

## Mathematical Scales Engine

Under the hood, Visage provides standalone scale functions:

<CodeBlock
  filename="scales.ts"
  lang="ts"
  code={`import { createLinearScale, createBandScale, generateTicks } from "@epoch32/visage/charts";

// 1. Continuous linear scale
const scaleY = createLinearScale([0, 100], [300, 0]);
console.log(scaleY(50)); // -> 150 (midpoint)

// Invert pixel position back to data domain
console.log(scaleY.invert(150)); // -> 50

// 2. Discrete category band scale
const scaleX = createBandScale(["Jan", "Feb", "Mar"], [0, 600], 0.2);
console.log(scaleX("Feb")); // -> band slot pixel offset
console.log(scaleX.bandwidth); // -> width of each bar`}
/>

## API Reference

### `<Chart>`

Root SVG chart provider establishing Cartesian coordinate domains, responsive viewBox dimensions, and mouse scrub listeners.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Chart(props: {
  data: any[] | ReadonlySignal<any[]>;
  width: number;
  height: number;
  xKey?: string;
  yKey?: string;
  children?: Element | Element[];
}): Element`}
/>

#### Props
- `data` (`any[] | ReadonlySignal<any[]>`): Array or reactive signal containing dataset records.
- `width` (`number`): SVG viewBox width coordinate space.
- `height` (`number`): SVG viewBox height coordinate space.
- `xKey` (`string`, optional): Property name for X-axis values.
- `yKey` (`string`, optional): Property name for Y-axis values.

<hr className="api-divider" />

### `<Line>`

Renders a continuous SVG path line visualization with optional monotonic cubic Bezier spline smoothing.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Line(props: {
  stroke?: string;
  strokeWidth?: number;
  smooth?: boolean;
  dot?: boolean;
}): Element`}
/>

#### Props
- `stroke` (`string`, optional): Stroke color or theme token.
- `strokeWidth` (`number`, optional): Line width in pixels.
- `smooth` (`boolean`, optional): Enables cubic Bezier spline interpolation.
- `dot` (`boolean`, optional): Renders marker points at each data coordinate.

<hr className="api-divider" />

### `<Area>`

Closed area polygon SVG visualization filled from the data curve to the bottom baseline.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Area(props: {
  fill?: string;
  fillOpacity?: number;
  stroke?: string;
  smooth?: boolean;
}): Element`}
/>

#### Props
- `fill` (`string`, optional): Fill color for the closed area.
- `fillOpacity` (`number`, optional): Opacity value (0 to 1).
- `stroke` (`string`, optional): Stroke color for the top boundary curve.
- `smooth` (`boolean`, optional): Enables cubic Bezier spline interpolation.

<hr className="api-divider" />

### `<Pie>`

Radial arc pie or donut chart with customizable inner/outer radii and slice padding angles.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Pie(props: {
  valueKey: string;
  labelKey?: string;
  donut?: boolean;
  innerRadius?: number;
}): Element`}
/>

#### Props
- `valueKey` (`string`): Property name corresponding to slice values.
- `labelKey` (`string`, optional): Property name corresponding to segment labels.
- `donut` (`boolean`, optional): When true, renders with an inner cutout radius.
- `innerRadius` (`number`, optional): Inner radius offset in pixels for donut rendering.
