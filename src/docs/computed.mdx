A computed node is a derived reactive container calculated from the values of one or more signals. Computed nodes cannot be written to manually; they exist strictly as pure transformations of upstream state.

## How Dirty Loading Works

In naive reactive systems, updating a signal immediately triggers an eager recalculation of every derived calculation connected to it. If you have a network of calculations that are currently offscreen, hidden in a collapsed accordion, or not currently rendered, that is wasted CPU time.

Visage solves this with **Dirty Loading**:

## Basic Syntax & Usage

To create a computed node, import `computed` from `@epoch32/visage` and pass a pure computation function. It returns a read-only signal accessor:

<CodeBlock
  filename="computed-basic.ts"
  lang="ts"
  code={`import { createSignal, computed } from "@epoch32/visage";

const [count, setCount] = createSignal(2);

// 1. Declare derived computed node
const double = computed(() => count() * 2);

// 2. Read the computed value by invoking it
console.log(double()); // -> 4

// 3. Update upstream signal
setCount(5);

// double is NOT calculated yet! It will calculate on next read:
console.log(double()); // -> 10`}
/>

## The Subscriber Tree

Every signal maintains an internal subscriber set of all nodes watching it. When a signal changes, it notifies each subscriber in its tree to mark itself dirty.

This dirtiness propagates recursively down the entire graph:

<CodeBlock
  filename="subscriber-tree.ts"
  lang="ts"
  code={`const [a, setA] = createSignal(1);
const b = computed(() => a() * 2);      // Depends on A
const c = computed(() => b() + 10);     // Depends on B
const d = computed(() => c() ** 2);     // Depends on C

// When A changes, A notifies B, B notifies C, and C notifies D.
// None of them run any math until someone reads d().`}
/>

## Memoization & Deduplication

Once computed, a node caches its output. Subsequent reads return the cached value directly without calling your function:

## Dynamic Dependency Pruning

Dependencies are not static. During each execution, Visage tracks precisely which signals were read during that specific run. Branches that were not taken unsubscribe automatically:

<CodeBlock
  filename="dynamic-dependencies.ts"
  lang="ts"
  code={`const [showAdmin, setShowAdmin] = createSignal(false);
const [userStats, setUserStats] = createSignal({ visits: 42 });
const [adminStats, setAdminStats] = createSignal({ revenue: 9999 });

const dashboardData = computed(() => {
  if (showAdmin()) {
    return adminStats(); // Subscribes to adminStats
  }
  return userStats();   // Subscribes to userStats
});

// While showAdmin() is false, changing adminStats() will NOT mark dashboardData dirty!`}
/>
