Because Visage components execute **exactly once** at mount time, traditional JavaScript expressions like ternary operators `condition ? <A /> : <B />` and `items.map()` do not automatically re-evaluate when signals change. Instead, Visage provides reactive control flow primitives: `<Show>` and `<For>`.

## Conditional Rendering (&lt;Show&gt;)

The `<Show>` component conditionally renders its children based on the truthiness of the `when` prop. It supports an optional `fallback` prop for falsey states:

<CodeBlock
  filename="ShowExample.tsx"
  lang="tsx"
  code={`import { Show, createSignal } from "@epoch32/visage";

function Profile() {
  const [user, setUser] = createSignal<{ name: string } | null>(null);

  return (
    <Show
      when={user}
      fallback={<button onClick={() => setUser({ name: "Alice" })}>Log In</button>}
    >
      {(item) => <div>Welcome back, {item().name}!</div>}
    </Show>
  );
}`}
/>

## Keyed List Reconciliation (&lt;For&gt;)

The `<For>` component renders a list of items with fine-grained referential stability. The children render callback receives the item along with a reactive `index` accessor function:

<CodeBlock
  filename="ForExample.tsx"
  lang="tsx"
  code={`import { For, createSignal } from "@epoch32/visage";

function FruitList() {
  const [fruits, setFruits] = createSignal(["Apple", "Banana", "Cherry"]);

  return (
    <ul>
      <For each={fruits} fallback={<li>No fruits available</li>}>
        {(fruit, index) => (
          <li>
            #{index() + 1}: {fruit}
          </li>
        )}
      </For>
    </ul>
  );
}`}
/>

## Type Narrowing with Accessor Children

In TypeScript, if your `when` condition evaluates a nullable object (such as `User | null`), you can pass a callback as the child. Visage supplies a narrowed accessor `() => User` where `null` and `undefined` are guaranteed to be filtered out:

<CodeBlock
  filename="type-narrowing.tsx"
  lang="tsx"
  code={`interface User {
  id: string;
  name: string;
  email: string;
}

const [currentUser, setCurrentUser] = createSignal<User | null>(null);

<Show when={currentUser} fallback={<div>Guest User</div>}>
  {/* 'user' is guaranteed to be an Accessor<User> (non-null!) */}
  {(user) => (
    <div>
      <h3>{user().name}</h3>
      <p>{user().email}</p>
    </div>
  )}
</Show>`}
/>

Developers coming from React often wonder why standard JavaScript loops and conditionals are discouraged in Visage JSX:
