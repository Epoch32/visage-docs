Visage I18n (`visage/i18n`) provides a zero-dependency, ultra-lightweight localization engine designed specifically for fine-grained reactive applications. Unlike traditional i18n libraries that force full virtual DOM component re-renders, Visage updates **only the targeted text nodes** when the active locale changes.

<FeatureGrid>
  <FeatureCard icon="zap" title="Zero Component Re-renders">
    Translations bind directly to signal subscribers. Switching languages updates on-screen text instantly without re-mounting components or re-running setup logic.
  </FeatureCard>

  <FeatureCard icon="users" title="Native Crowdin & Weblate Sync">
    Accepts standard JSON key-value and nested dictionaries produced by community translation platforms, with in-context live visual editing tags.
  </FeatureCard>
</FeatureGrid>

## Quickstart (createI18n)

Initialize your translation engine with preloaded dictionaries or dynamic loaders:

<CodeBlock
  filename="src/i18n.ts"
  lang="ts"
  code={`import { createI18n } from "@epoch32/visage";

export const i18n = createI18n({
  defaultLocale: "en",
  fallbackLocale: "en",
  translations: {
    en: {
      nav: { home: "Home", docs: "Documentation" },
      welcome: "Welcome, {{name}}!",
      items: {
        zero: "No items",
        one: "1 item",
        other: "{{count}} items"
      }
    },
    es: {
      nav: { home: "Inicio", docs: "Documentación" },
      welcome: "¡Bienvenido, {{name}}!",
      items: {
        zero: "Ningún artículo",
        one: "1 artículo",
        other: "{{count}} artículos"
      }
    }
  }
});

export const { t, locale, setLocale, formatNumber, formatDate } = i18n;`}
/>

## Fine-Grained Reactive Translations

Use `t(...)` inside reactive JSX bindings. When `setLocale("es")` is called, only the text node is updated in place:

<CodeBlock
  filename="Header.tsx"
  lang="tsx"
  code={`import { t, locale, setLocale } from "./i18n";

export function Header() {
  return (
    <header>
      <h1>{() => t("welcome", { name: "Alice" })}</h1>
      <p>{() => t("nav.docs")}</p>

      <div class="lang-switcher">
        <button
          type="button"
          class={() => (locale() === "en" ? "active" : "")}
          onClick={() => setLocale("en")}
        >
          English
        </button>
        <button
          type="button"
          class={() => (locale() === "es" ? "active" : "")}
          onClick={() => setLocale("es")}
        >
          Español
        </button>
      </div>
    </header>
  );
}`}
/>

## CLDR Standard Pluralization

Pluralization rules vary drastically between languages (e.g. Arabic has 6 plural forms, Slavic languages have 3, English has 2). Visage utilizes the browser's native `Intl.PluralRules` to select the exact grammatical form:

<CodeBlock
  filename="CartSummary.tsx"
  lang="tsx"
  code={`// Definition in translation JSON:
// "items": {
//   "zero": "No items in cart",
//   "one": "{{count}} item in cart",
//   "few": "{{count}} items in cart",
//   "many": "{{count}} items in cart",
//   "other": "{{count}} items in cart"
// }

export function CartBadge({ count }: { count: () => number }) {
  return <span>{() => t("items", { count: count() })}</span>;
}`}
/>

## Crowdin & Weblate Community Integration

Community localization workflows sync translation files straight to your GitHub repository or stream them over-the-air:

### 1. Git-Based Sync (Crowdin / Weblate PRs)
Store translation files in a standard `locales/` directory:
```
locales/
  ├── en.json       <-- Source strings committed with your code
  ├── es.json       <-- Auto-committed / PR'd by community translators
  ├── de.json
  └── ja.json
```
Import or load them directly into Visage with zero conversion.

### 2. Dynamic / OTA Async Dictionaries (Crowdin OTA / CDN)
For large applications or over-the-air translation updates without deploying a new app version, supply an asynchronous `loader`:

<CodeBlock
  filename="i18n-loader.ts"
  lang="ts"
  code={`import { createI18n } from "@epoch32/visage";

export const i18n = createI18n({
  defaultLocale: "en",
  fallbackLocale: "en",
  async loader(locale) {
    // 1. Fetch live from Crowdin Over-The-Air CDN or API
    const res = await fetch(\`https://distributions.crowdin.net/your-project/\${locale}.json\`);
    if (res.ok) return await res.json();

    // 2. Fall back to bundled local JSON
    return import(\`./locales/\${locale}.json\`);
  }
});`}
/>

### 3. In-Context Visual Editing

Crowdin and Weblate provide In-Context editing modes where translators view your live app and edit strings in a popup modal. Enable `inContext: true` to wrap strings in standard translation tags:

<CodeBlock
  filename="in-context-config.ts"
  lang="ts"
  code={`export const i18n = createI18n({
  defaultLocale: "en",
  // In dev / preview mode: wraps output with <!-- crwdns:key -->text<!-- /crwdns -->
  inContext: process.env.NODE_ENV === "development"
});`}
/>

## Native Intl Date & Number Formatting

Visage includes cached helpers for browser-native formatting tied directly to the active locale signal:

<CodeBlock
  filename="FormatExamples.ts"
  lang="ts"
  code={`import { formatNumber, formatDate, formatRelativeTime } from "./i18n";

// Currency formatting
formatNumber(12500.5, { style: "currency", currency: "USD" }); // "$12,500.50"

// Date formatting
formatDate(new Date(), { dateStyle: "long" }); // "October 12, 2026"

// Relative time formatting
formatRelativeTime(-1, "day", { numeric: "auto" }); // "yesterday"`}

## API Reference

### `createI18n()`

Creates a fine-grained reactive internationalization instance.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function createI18n(options?: CreateI18nOptions): I18nInstance`}
/>

#### Options
- `defaultLocale` (`string`, *optional*): Initial active locale. Defaults to `"en"`.
- `fallbackLocale` (`string`, *optional*): Fallback locale when a key is missing. Defaults to `"en"`.
- `translations` (`TranslationsDict`, *optional*): Preloaded locale translation dictionaries.
- `loader` (`(locale: string) => Promise<TranslationRecord>`, *optional*): Asynchronous dynamic dictionary loader for code splitting or OTA CDN loading.
