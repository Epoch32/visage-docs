Rendering tens of thousands of DOM nodes causes severe browser memory bloat and sluggish scrolling. Visage includes a high-performance virtualization engine (`visage/virtual`) capable of rendering 100,000+ items at constant 60fps with sub-millisecond scrolling latency.

## Virtual List (&lt;VirtualList&gt;)

Use `<VirtualList>` to virtualize large vertical lists with fixed or estimated item heights:

<CodeBlock
  filename="VirtualListExample.tsx"
  lang="tsx"
  code={`import { VirtualList } from "@epoch32/visage/virtual";

interface LogEntry {
  id: string;
  timestamp: string;
  message: string;
}

// 100,000 items
const bigDataset: LogEntry[] = Array.from({ length: 100_000 }, (_, i) => ({
  id: \`log-\${i}\`,
  timestamp: new Date(Date.now() - i * 1000).toISOString(),
  message: \`Packet transmission confirmed for node \${i}\`,
}));

export function SystemLogViewer() {
  return (
    <VirtualList
      items={bigDataset}
      height={500}
      estimateSize={44}
      overscan={6}
      renderItem={(item, index) => (
        <div class="log-row">
          <span class="log-index">#{index()}</span>
          <span class="log-time">{item.timestamp}</span>
          <span class="log-msg">{item.message}</span>
        </div>
      )}
    />
  );
}`}
/>

Props:
- `items`: Array or reactive signal containing list data.
- `height`: Container height in pixels or CSS dimension string (e.g. `500` or `"100%"`).
- `estimateSize`: Fixed number or function returning expected item height in pixels.
- `overscan`: Number of offscreen items rendered above and below the visible viewport (default `5`).
- `renderItem`: Callback receiving `(item: T, index: () => number)` and returning a `Child`.

## Dynamic Variable Heights

When items have unpredictable content heights (e.g., chat messages or multi-line comments), Visage calculates dynamic positions using prefix-sum offsets and DOM measurement:

<CodeBlock
  filename="VariableHeights.tsx"
  lang="tsx"
  code={`import { VirtualList } from "@epoch32/visage/virtual";

export function ChatFeed({ messages }: { messages: string[] }) {
  return (
    <VirtualList
      items={messages}
      height="100dvh"
      estimateSize={(index) => (index % 3 === 0 ? 80 : 44)}
      overscan={8}
      renderItem={(msg) => (
        <div class="chat-bubble">
          <p>{msg}</p>
        </div>
      )}
    />
  );
}`}
/>

## Headless Virtualizer (createVirtualizer)

For custom scroll containers, tables, or window-scrolling layouts, use the headless `createVirtualizer` hook:

<CodeBlock
  filename="HeadlessVirtualizer.ts"
  lang="ts"
  code={`import { createVirtualizer } from "@epoch32/visage/virtual";

let scrollContainerRef: HTMLDivElement | null = null;

const virtualizer = createVirtualizer({
  count: 50_000,
  getScrollElement: () => scrollContainerRef,
  estimateSize: () => 48,
  overscan: 5,
});

// Query visible items
const visibleRows = virtualizer.getVirtualItems();
const totalHeight = virtualizer.getTotalSize();

// Programmatic scrolling
virtualizer.scrollToIndex(2500, { align: "center" });`}
/>

## 2D Grid Virtualization (&lt;VirtualGrid&gt;)

Virtualize massive 2D grids (e.g. spreadsheets or photo galleries) with bidirectional row and column virtualization:

<CodeBlock
  filename="VirtualGridExample.tsx"
  lang="tsx"
  code={`import { VirtualGrid } from "@epoch32/visage/virtual";

export function SpreadsheetView() {
  return (
    <VirtualGrid
      rowCount={10_000}
      columnCount={100}
      rowHeight={32}
      columnWidth={120}
      height={600}
      width={900}
      renderCell={(row, col) => (
        <div class="spreadsheet-cell">
          R{row} C{col}
        </div>
      )}
    />
  );
}`}
/>
