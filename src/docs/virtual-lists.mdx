Rendering tens of thousands of DOM nodes causes severe browser memory bloat and sluggish scrolling. Visage includes a high-performance virtualization engine (`@epoch32/visage/virtual`) capable of rendering 100,000+ items at constant 60fps with sub-millisecond scrolling latency.

<FeatureGrid>
  <FeatureCard icon="zap" title="Constant DOM Footprint">
    Only mounts the exact slice of visible DOM nodes plus a configurable overscan buffer. 100,000 items consume the same DOM memory as 20 items.
  </FeatureCard>

  <FeatureCard icon="cpu" title="Fine-Grained Item Updates">
    Mutations to individual items update through signal accessors without re-virtualizing or remounting the rest of the list.
  </FeatureCard>

  <FeatureCard icon="layers" title="2D Bidirectional Virtualization">
    <code>&lt;VirtualGrid&gt;</code> virtualizes both rows and columns simultaneously with custom cell key tracking to prevent unneeded DOM churn.
  </FeatureCard>
</FeatureGrid>

## Virtual List (&lt;VirtualList&gt;)

Use `<VirtualList>` to virtualize large vertical lists with fixed or dynamic item heights:

<CodeBlock
  filename="VirtualListExample.tsx"
  lang="tsx"
  code={`import { VirtualList } from "@epoch32/visage/virtual";

interface LogEntry {
  id: string;
  timestamp: string;
  message: string;
}

// 100,000 items
const bigDataset: LogEntry[] = Array.from({ length: 100_000 }, (_, i) => ({
  id: \`log-\${i}\`,
  timestamp: new Date(Date.now() - i * 1000).toISOString(),
  message: \`Packet transmission confirmed for node \${i}\`,
}));

export function SystemLogViewer() {
  return (
    <VirtualList
      each={bigDataset}
      height={500}
      itemHeight={44}
      overscan={5}
    >
      {(item, index) => (
        <div class="log-row">
          <span class="log-index">#{() => index() + 1}</span>
          <span class="log-time">{item.timestamp}</span>
          <span class="log-msg">{item.message}</span>
        </div>
      )}
    </VirtualList>
  );
}`}
/>

Props:
- `each`: Array or reactive signal returning list data.
- `height`: Container height in pixels or CSS dimension string (default `400`).
- `width`: Container width in pixels or CSS dimension string (default `"100%"`).
- `itemHeight`: Fixed number or function returning item height in pixels `(index: number) => number`.
- `overscan`: Number of offscreen items rendered above and below the visible viewport (default `3`).
- `children`: Item template function receiving `(item: T, index: () => number) => any`.

## Dynamic Variable Heights

When items have variable heights based on index or content, pass a sizing function to `itemHeight`:

<CodeBlock
  filename="VariableHeights.tsx"
  lang="tsx"
  code={`import { VirtualList } from "@epoch32/visage/virtual";

export function ChatFeed({ messages }: { messages: string[] }) {
  return (
    <VirtualList
      each={messages}
      height="100dvh"
      itemHeight={(index) => (index % 3 === 0 ? 80 : 44)}
      overscan={6}
    >
      {(msg, index) => (
        <div class="chat-bubble">
          <span class="text-xs text-zinc-500">Msg #{() => index() + 1}</span>
          <p>{msg}</p>
        </div>
      )}
    </VirtualList>
  );
}`}
/>

## 2D Grid Virtualization (&lt;VirtualGrid&gt;)

Virtualize massive 2D grids (e.g. spreadsheets or data tables) with bidirectional row and column virtualization:

<CodeBlock
  filename="VirtualGridExample.tsx"
  lang="tsx"
  code={`import { VirtualGrid } from "@epoch32/visage/virtual";

// 10,000 rows x 100 columns matrix
const matrix = Array.from({ length: 10_000 }, (_, r) =>
  Array.from({ length: 100 }, (_, c) => ({
    id: \`cell-\${r}-\${c}\`,
    value: \`R\${r}C\${c}\`,
  }))
);

export function SpreadsheetView() {
  return (
    <VirtualGrid
      data={matrix}
      rowHeight={32}
      columnWidth={120}
      height={600}
      width={900}
      overscan={3}
    >
      {(cell, row, col) => (
        <div class="spreadsheet-cell">
          {cell.value}
        </div>
      )}
    </VirtualGrid>
  );
}`}
/>

## Cell Identity with getItemKey

When scrolling fast through 2D grids or updating cell data asynchronously, use `getItemKey` to preserve DOM identity and state (such as input focus or CSS animations) across render passes:

<CodeBlock
  filename="SpreadsheetWithKeys.tsx"
  lang="tsx"
  code={`import { VirtualGrid } from "@epoch32/visage/virtual";

<VirtualGrid
  data={matrix}
  rowHeight={36}
  columnWidth={140}
  height={600}
  width="100%"
  // Retains exact DOM element identity across virtualizer viewport shifts
  getItemKey={(cell, row, col) => cell.id}
>
  {(cell, row, col) => (
    <input
      type="text"
      value={cell.value}
      class="border border-zinc-700 bg-transparent px-2 w-full h-full"
    />
  )}
</VirtualGrid>`}
/>

`VirtualGrid` automatically parses string or numeric heights and widths to pre-calculate scroll offsets on initial render before layout measurements occur, preventing layout shift flickers.

## Headless Virtualizer (createVirtualizer)

For custom scroll containers or arbitrary layouts, use the headless `createVirtualizer` primitive:

<CodeBlock
  filename="HeadlessVirtualizer.ts"
  lang="tsx"
  code={`import { createVirtualizer } from "@epoch32/visage/virtual";
import { signal, For } from "@epoch32/visage";

export function CustomVirtualScroll() {
  const containerRef = signal<HTMLDivElement | null>(null);

  const virtualizer = createVirtualizer({
    count: 50_000,
    itemHeight: 48,
    overscan: 4,
    getScrollElement: () => containerRef(),
  });

  return (
    <div
      ref={(el) => containerRef.set(el)}
      style={{ height: "400px", overflow: "auto", position: "relative" }}
    >
      <div style={() => ({ height: \`\${virtualizer.totalSize()}px\`, position: "relative" })}>
        <For each={virtualizer.virtualItems} by={(item) => item.key}>
          {(item) => (
            <div
              style={() => ({
                position: "absolute",
                top: 0,
                left: 0,
                width: "100%",
                height: \`\${item.size}px\`,
                transform: \`translateY(\${item.start}px)\`,
              })}
            >
              Item #{item.index}
            </div>
          )}
        </For>
      </div>
    </div>
  );
}`}
/>

## API Reference

### VirtualList Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `each` | `T[] \| (() => T[])` | Required | Array or reactive accessor containing dataset items. |
| `itemHeight` | `number \| ((index: number) => number)` | Required | Fixed height or dynamic sizing function. |
| `height` | `number \| string` | `400` | Container viewport height. |
| `width` | `number \| string` | `"100%"` | Container viewport width. |
| `overscan` | `number` | `3` | Offscreen buffer rows rendered above and below viewport. |
| `class` | `string` | `undefined` | CSS class string on scroll container element. |
| `style` | `Record<string, any> \| (() => Record<string, any>)` | `undefined` | Inline style overrides on scroll container. |
| `children` | `(item: T, index: () => number) => any` | Required | Render template function. |

### VirtualGrid Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `data` | `T[][] \| (() => T[][])` | Required | 2D matrix array or reactive accessor. |
| `rowHeight` | `number` | Required | Fixed row height in pixels. |
| `columnWidth` | `number` | Required | Fixed column width in pixels. |
| `height` | `number \| string` | `400` | Container viewport height. |
| `width` | `number \| string` | `400` | Container viewport width. |
| `overscan` | `number` | `3` | Buffer cells rendered outside visible bounds. |
| `getItemKey` | `(item: T, row: number, col: number) => any` | `undefined` | Custom cell key identifier to preserve DOM identity. |
| `children` | `(item: T, row: number, col: number) => any` | Required | Cell render template function. |
