## Tactile Glass (glass)

The `glass()` helper generates modern frosted glass styling. It applies `backdropFilter`, WebKit prefixes, background tint, and subtle border highlights:

<CodeBlock
  filename="GlassExample.tsx"
  lang="tsx"
  code={`import { glass, Stack } from "@epoch32/visage";

export function FloatingDock() {
  return (
    <Stack
      p={3}
      style={{
        ...glass({ blur: 16, tint: "rgba(255, 255, 255, 0.7)" }),
        borderRadius: "16px",
        boxShadow: "0 20px 25px -5px rgba(0, 0, 0, 0.1)",
      }}
    >
      <div class="dock-content">Dock Navigation</div>
    </Stack>
  );
}`}
/>

Options for `glass()`:
- `blur`: Blur radius in pixels or CSS string (default `"20px"`).
- `tint`: Background fill color (default `"rgba(255, 255, 255, 0.65)"`).
- `border`: Border stroke (default `"1px solid rgba(255, 255, 255, 0.75)"`).

## Optical Depth Shadows (shadow)

Visage includes calibrated shadow tokens that simulate real physical light dispersion across layers:

<CodeBlock
  filename="ShadowTokens.ts"
  lang="ts"
  code={`import { shadow } from "@epoch32/visage";

shadow("sm");   // "0 1px 2px 0 rgba(0, 0, 0, 0.05)"
shadow("md");   // "0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -2px rgba(0, 0, 0, 0.1)"
shadow("lg");   // "0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -4px rgba(0, 0, 0, 0.1)"
shadow("xl");   // "0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1)"
shadow("soft"); // "0 8px 30px rgba(0, 0, 0, 0.06)" (ambient diffused card shadow)
shadow("glow"); // "0 0 24px rgba(168, 85, 247, 0.35)" (accent neon glow)
shadow("inner");// "inset 0 2px 4px 0 rgba(0, 0, 0, 0.06)"`}
/>

## Curvature Radii (radius)

Consistent border radii create visual harmony across nested cards, buttons, and popovers:

<CodeBlock

## API Reference

### `glass()`

Generates tactile frosted glass styles with cross-browser backdrop filter blurs, background tinting, and light-reflective border accents.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function glass(options?: {
  blur?: number | string;
  tint?: string;
  border?: string;
}): Record<string, string>`}
/>

#### Parameters
- `options` (`GlassOptions`, optional): Configuration object.
  - `blur` (`number | string`, optional): Backdrop blur radius in pixels or CSS measurement. Defaults to `"20px"`.
  - `tint` (`string`, optional): Translucent background fill color. Defaults to `"rgba(255, 255, 255, 0.65)"`.
  - `border` (`string`, optional): Border stroke CSS string. Defaults to `"1px solid rgba(255, 255, 255, 0.75)"`.

#### Returns
- `Record<string, string>`: Style object containing CSS properties for backdrop-filter, background, and border.

<hr className="api-divider" />

### `shadow()`

Returns calibrated multi-layer box shadows designed for optical depth (`sm`, `md`, `lg`, `xl`, `soft`, `glow`, `inner`).

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function shadow(variant: ShadowVariant | string): string`}
/>

#### Parameters
- `variant` (`ShadowVariant | string`): Shadow tier keyword name or custom elevation string.

#### Returns
- `string`: Complete CSS `box-shadow` property string.

<hr className="api-divider" />

### `radius()`

Returns standardized curvature radii (`sm`, `md`, `lg`, `xl`, `2xl`, `3xl`, `full` or explicit numbers in pixels).

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function radius(variant: RadiusVariant | number): string`}
/>

#### Parameters
- `variant` (`RadiusVariant | number`): Curvature step identifier or number in pixels.

#### Returns
- `string`: CSS `border-radius` measurement string.
