## Data Table (&lt;DataTable&gt;)

The `<DataTable>` primitive delivers high-performance tabular data presentation with fine-grained column sorting, search filtering, row selection, and pagination:

<CodeBlock
  filename="DataTableExample.tsx"
  lang="tsx"
  code={`import { DataTable, type ColumnDef, createSignal } from "@epoch32/visage";

interface User {
  id: string;
  name: string;
  email: string;
  role: string;
}

const users: User[] = [
  { id: "1", name: "Alice Smith", email: "alice@example.com", role: "Admin" },
  { id: "2", name: "Bob Jones", email: "bob@example.com", role: "Engineer" },
  { id: "3", name: "Carol Vance", email: "carol@example.com", role: "Designer" },
];

const columns: ColumnDef<User>[] = [
  { header: "Name", accessorKey: "name", sortable: true },
  { header: "Email", accessorKey: "email" },
  { header: "Role", accessorKey: "role", sortable: true },
];

export function UserDirectory() {
  const [selectedIds, setSelectedIds] = createSignal<string[]>([]);

  return (
    <DataTable
      data={users}
      columns={columns}
      searchKey="name"
      pageSize={10}
      sortable={true}
      selectable={true}
      selectedRowIds={selectedIds}
      onSelectionChange={setSelectedIds}
      getRowId={(user) => user.id}
    />
  );
}`}
/>

Under the hood, `<DataTable>` wraps sorting and filtering in memoized `computed()` signals and keys rows in `<For by={getRowId}>` so existing table rows and input focus states are preserved in-place rather than destroyed during sorts.

## Popover & CSS Anchor Positioning (&lt;Popover&gt;)

The Popover primitive positions non-modal floating overlays with click-outside and Escape key dismissal. It supports both standard signal-based positioning and cutting-edge **Browser-Native Popover API** with **CSS Anchor Positioning**:

<CodeBlock
  filename="PopoverExample.tsx"
  lang="tsx"
  code={`import {
  Popover,
  PopoverTrigger,
  PopoverPortal,
  PopoverContent,
  PopoverClose,
} from "@epoch32/visage";

export function SettingsPopover() {
  return (
    // Enable native HTML Popover and CSS Anchor Positioning:
    <Popover native={true} anchorName="--filter-anchor">
      <PopoverTrigger class="btn">Filters</PopoverTrigger>

      <PopoverPortal>
        <PopoverContent
          side="bottom"
          positionArea="block-end span-inline-end"
          class="popover-card"
        >
          <h4>Filter Results</h4>
          <label>
            <input type="checkbox" /> Include Archived
          </label>
          <PopoverClose class="btn btn-sm">Done</PopoverClose>
        </PopoverContent>
      </PopoverPortal>
    </Popover>
  );
}`}
/>

### Native HTML Popover API

Passing `native={true}` (or `popover="auto"` / `popover="manual"` on `<PopoverContent>`) promotes the overlay directly into the browser's top layer. The browser natively manages light-dismiss (clicking outside or pressing Escape) without complex document listeners, and Visage automatically synchronizes the browser's `toggle` events with your reactive signals.

### Declarative CSS Anchor Positioning

Using `side="top" | "bottom" | "left" | "right"` or `positionArea="block-end span-inline-end"` automatically applies CSS Anchor Positioning (`anchor-name`, `position-anchor`, `position-area`, `position-try-fallbacks`, `inset: auto`). The browser flips the overlay on overflow without executing expensive `getBoundingClientRect()` scroll calculations in JavaScript!

### `useDismiss()`

Headless dismiss primitive unifying Escape key listening, pointer click-outside detection, focus trapping, and close selector delegation.

<CodeBlock
  lang="ts"
  filename="signature"
  code={`function useDismiss(
  target: () => HTMLElement | null,
  options: {
    enabled?: boolean | (() => boolean);
    onDismiss: () => void;
    escapeKey?: boolean;
    outsidePointer?: boolean;
    trapFocus?: boolean;
  }
): void`}
/>

#### Parameters
- `target` (`() => HTMLElement | null`): Accessor returning the container element to protect against dismiss events.
- `options` (`UseDismissOptions`): Configuration object.
  - `enabled` (`boolean | (() => boolean)`, optional): Whether dismiss listeners are active. Defaults to `true`.
  - `onDismiss` (`() => void`): Callback invoked when Escape or click-outside occurs.
  - `escapeKey` (`boolean`, optional): Dismiss on Escape key press. Defaults to `true`.
  - `outsidePointer` (`boolean`, optional): Dismiss on pointer clicks outside the target element. Defaults to `true`.
  - `trapFocus` (`boolean`, optional): Confines Tab focus cycles within target children. Defaults to `false`.

#### Returns
- `void`
