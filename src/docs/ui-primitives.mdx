## Dialog / Modal (&lt;Dialog&gt;)

The Dialog primitive renders accessible modal dialogs with backdrop overlay, focus trapping, and Escape key dismissal:

<CodeBlock
  filename="DialogExample.tsx"
  lang="tsx"
  code={`import {
  Dialog,
  DialogTrigger,
  DialogPortal,
  DialogOverlay,
  DialogContent,
  DialogTitle,
  DialogDescription,
  DialogClose,
} from "@epoch32/visage";

export function ConfirmDeleteDialog() {
  return (
    <Dialog>
      <DialogTrigger class="btn btn-danger">Delete Project</DialogTrigger>

      <DialogPortal>
        <DialogOverlay class="dialog-overlay" />
        <DialogContent class="dialog-content">
          <DialogTitle>Are you absolutely sure?</DialogTitle>
          <DialogDescription>
            This action cannot be undone. This will permanently delete your workspace repository.
          </DialogDescription>

          <div style={{ display: "flex", justifyContent: "flex-end", gap: "8px", marginTop: "16px" }}>
            <DialogClose class="btn">Cancel</DialogClose>
            <button class="btn btn-danger">Confirm Delete</button>
          </div>
        </DialogContent>
      </DialogPortal>
    </Dialog>
  );
}`}
/>

## Select (&lt;Select&gt;)

The Select primitive provides an accessible, keyboard-navigable combobox/select dropdown with auto-anchoring, option highlighting, and full type safety:

<CodeBlock
  filename="SelectExample.tsx"
  lang="tsx"
  code={`import { Select, createSignal } from "@epoch32/visage";

export function ThemePicker() {
  const [theme, setTheme] = createSignal("dark");

  return (
    <Select
      value={theme}
      onValueChange={setTheme}
      options={[
        { label: "Light", value: "light" },
        { label: "Dark", value: "dark" },
        { label: "System", value: "system" },
      ]}
      placeholder="Select theme..."
    />
  );
}`}
/>

## Slider (&lt;Slider&gt;)

The Slider primitive renders an accessible continuous range slider with keyboard navigation (ArrowLeft, ArrowRight, PageUp, PageDown, Home, End) and touch/mouse dragging:

<CodeBlock
  filename="SliderExample.tsx"
  lang="tsx"
  code={`import { Slider, createSignal } from "@epoch32/visage";

export function VolumeSlider() {
  const [volume, setVolume] = createSignal(75);

  return (
    <div style={{ width: "240px" }}>
      <label>Volume: {volume}%</label>
      <Slider
        value={volume}
        onValueChange={setVolume}
        min={0}
        max={100}
        step={1}
      />
    </div>
  );
}`}
/>

## Command Palette (&lt;Command&gt;)

Visage includes a high-performance command palette for fuzzy search and keyboard action bars:

<CodeBlock
  filename="CommandExample.tsx"
  lang="tsx"
  code={`import {
  CommandDialog,
  CommandInput,
  CommandList,
  CommandEmpty,
  CommandGroup,
  CommandItem,
  createSignal,
} from "@epoch32/visage";

export function QuickCommand() {
  const [open, setOpen] = createSignal(false);

  return (
    <div>
      <button onClick={() => setOpen(true)}>Press Cmd+K</button>

      <CommandDialog open={open} onOpenChange={setOpen}>
        <CommandInput placeholder="Search commands, docs, or files..." />
        <CommandList>
          <CommandEmpty>No matches found.</CommandEmpty>

          <CommandGroup heading="Navigation">
            <CommandItem onSelect={() => { setOpen(false); }}>
              Go to Dashboard
            </CommandItem>
            <CommandItem onSelect={() => { setOpen(false); }}>
              Open Documentation
            </CommandItem>
          </CommandGroup>
        </CommandList>
      </CommandDialog>
    </div>
  );
}`}
/>

## Reactive Toasts (toast)

Trigger fine-grained toast notifications imperatively from anywhere in your application:

<CodeBlock
  filename="ToastUsage.tsx"
  lang="tsx"
  code={`import { toast } from "@epoch32/visage";

// 1. Success notification
toast.success("File saved successfully!");

// 2. Error alert
toast.error("Network error: Failed to connect to server");

// 3. Information toast
toast.info("A new release is available.");

// 4. Async promise notification
toast.promise(
  fetch("/api/deploy", { method: "POST" }),
  {
    loading: "Deploying build...",
    success: "Deployment completed!",
    error: "Deployment failed.",
  }
);`}
/>

Place the `<ToastViewport />` at the root of your application shell to render active toast stacks.

## Headless Dismiss (useDismiss)

Visage exports the shared `useDismiss` hook for building custom overlay primitives:

<CodeBlock
  filename="useDismissCustom.ts"
  lang="ts"
  code={`import { useDismiss } from "@epoch32/visage";

const dismiss = useDismiss(() => containerRef.current, {
  enabled: () => isOpen(),
  onDismiss: () => setIsOpen(false),
  escapeKey: true,
  outsidePointer: true,
  trapFocus: true,
  closeSelector: "[data-close-button]",
});`}
/>
