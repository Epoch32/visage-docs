### Resolving Spatial Values

Use `space()` to programmatically resolve scale values:

<CodeBlock
  filename="spatial-usage.ts"
  lang="ts"
  code={`import { space } from "@epoch32/visage";

space(1);      // "4px"
space(2);      // "8px"
space(4);      // "16px"
space(8);      // "32px"
space("full"); // "100%"
space("screen"); // "100dvh"`}
/>

## Semantic Dimension Keywords

Instead of hardcoding percentages or viewport units, Visage provides semantic strings that resolve consistently across browsers:

<CodeBlock
  filename="keywords.ts"
  lang="ts"
  code={`import { resolveDimension } from "@epoch32/visage";

resolveDimension("screen");       // "100dvh" (dynamic viewport height)
resolveDimension("screen-w");     // "100dvw" (dynamic viewport width)
resolveDimension("full");         // "100%"
resolveDimension("half");         // "50%"
resolveDimension("third");        // "33.333333%"
resolveDimension("two-thirds");    // "66.666667%"
resolveDimension("quarter");       // "25%"
resolveDimension("three-quarters"); // "75%"
resolveDimension("fit");          // "fit-content"
resolveDimension("min");          // "min-content"
resolveDimension("max");          // "max-content"`}
/>

## Fluid Clamping (fluid)

Creating responsive typography or spacing that smoothly scales from mobile to desktop without abrupt breakpoint jumps usually requires complex linear slope mathematics.

Visage's `fluid()` function calculates exact `clamp()` expressions automatically:

<CodeBlock
  filename="fluid-example.ts"
  lang="ts"
  code={`import { fluid } from "@epoch32/visage";

// Scales smoothly from 16px at 375px viewport to 32px at 1280px viewport:
const responsiveTitle = fluid(16, 32);
// Output: "clamp(16px, 9.38px + 1.77vw, 32px)"

// Custom viewport bounds:
const heroHeadline = fluid(24, 64, { minVw: 480, maxVw: 1600 });`}
/>
