Visage provides an opinionated full-stack file-based API framework (`visage/api`). It combines file system routing with end-to-end typed procedures, Standard Schema v1 validation, and composable middleware pipelines.

## Defining Procedures (query & mutation)

Procedures are defined using the builder pattern with `procedure`, `query()`, and `mutation()`:

<CodeBlock
  filename="api/users/profile.ts"
  lang="ts"
  code={`import { query, mutation, v } from "@epoch32/visage/api";

// 1. Read-only query
export const getProfile = query()
  .input(v.object({ userId: v.string() }))
  .handler(async ({ input }) => {
    return {
      id: input.userId,
      name: "Alice Developer",
      role: "admin",
    };
  });

// 2. Mutation with side effects
export const updateBio = mutation()
  .input(v.object({
    userId: v.string(),
    bio: v.string().max(280),
  }))
  .handler(async ({ input }) => {
    // Save to database...
    return { success: true, updatedBio: input.bio };
  });`}
/>

## Input Validation

Visage natively supports any schema library adhering to the **Standard Schema v1** specification:

<CodeBlock
  filename="validation-options.ts"
  lang="ts"
  code={`import { mutation, v } from "@epoch32/visage/api";
import { type } from "arktype"; // ArkType
import { z } from "zod";         // Zod

// 1. Built-in zero-dependency validator
const builtInProcedure = mutation()
  .input(v.object({ email: v.string().email() }));

// 2. ArkType schema
const arktypeProcedure = mutation()
  .input(type({ email: "string.email", age: "number>=18" }));

// 3. Zod schema
const zodProcedure = mutation()
  .input(z.object({ email: z.string().email(), age: z.number().min(18) }));`}
/>

If validation fails, Visage automatically halts execution and returns a typed `BAD_REQUEST` error payload with formatted field error messages.

## Type-Safe Middleware (defineMiddleware)

Middleware functions can inspect request headers, authenticate tokens, modify context, or guard endpoints:

<CodeBlock
  filename="api/_middleware.ts"
  lang="ts"
  code={`import { defineMiddleware, RPCError } from "@epoch32/visage/api";

export const authMiddleware = defineMiddleware(async ({ ctx, next }) => {
  const token = ctx.req.headers.get("authorization");

  if (!token) {
    throw new RPCError("UNAUTHORIZED", "Missing authorization bearer token");
  }

  // Extend context for downstream handlers:
  const user = { id: "user-123", role: "admin" };
  return next({ ctx: { ...ctx, user } });
});`}
/>

Attach middleware to individual procedures using `.use()`:

<CodeBlock
  filename="api/admin/metrics.ts"
  lang="ts"
  code={`import { query } from "@epoch32/visage/api";
import { authMiddleware } from "../_middleware";

export const getMetrics = query()
  .use(authMiddleware)
  .handler(async ({ ctx }) => {
    // ctx.user is fully typed!
    return { systemLoad: 0.42, user: ctx.user.id };
  });`}
/>

## Calling APIs from Client

On the frontend, instantiate the typed client to invoke procedures with full IDE autocomplete:

<CodeBlock
  filename="client-call.ts"
  lang="ts"
  code={`import { createApiClient } from "@epoch32/visage/api";
import type { AppApi } from "./server";

const api = createApiClient<AppApi>({ baseUrl: "/api" });

// Fully typechecked input and return value
const profile = await api.users.profile.getProfile({ userId: "101" });
console.log(profile.name); // "Alice Developer"`}
/>
