Visage RPC (`visage/rpc`) is a lightweight, zero-boilerplate alternative to tRPC and REST APIs. It provides full end-to-end type safety between client and server, automatic microtask query batching, and real-time Server-Sent Events (SSE) streaming without heavy runtime dependencies.

<FeatureGrid>
  <FeatureCard icon="zap" title="Microtask Query Batching">
    Multiple concurrent queries triggered across separate components automatically batch into a single HTTP POST request, eliminating network waterfalls.
  </FeatureCard>

  <FeatureCard icon="radio" title="Native SSE Streaming">
    First-class <code>subscription()</code> procedures stream real-time events over Server-Sent Events with automatic reconnection and typed data channels.
  </FeatureCard>
</FeatureGrid>

## Defining an RPC Router (createRouter)

Define your API procedures using `createRouter`, `query`, `mutation`, and `subscription`:

<CodeBlock
  filename="server/router.ts"
  lang="ts"
  code={`import { createRouter, query, mutation, subscription, v } from "@epoch32/visage/rpc";

export const appRouter = createRouter({
  // 1. Read query
  getUser: query({
    input: v.object({ id: v.string() }),
    resolve: async ({ input }) => {
      return { id: input.id, name: "Alice", tier: "pro" };
    },
  }),

  // 2. Mutation
  createPost: mutation({
    input: v.object({ title: v.string(), content: v.string() }),
    resolve: async ({ input }) => {
      return { postId: "post-99", title: input.title };
    },
  }),

  // 3. SSE subscription (Async Generator)
  liveMetrics: subscription({
    input: v.object({ intervalMs: v.number().optional() }),
    resolve: async function* ({ input }) {
      const intervalMs = input.intervalMs ?? 1000;
      while (true) {
        await new Promise((r) => setTimeout(r, intervalMs));
        yield { timestamp: Date.now(), cpu: Math.random() * 100 };
      }
    },
  }),
});

export type AppRouter = typeof appRouter;`}
/>

Alternatively, procedures can be registered fluidly with method chaining:

<CodeBlock
  filename="server/chained-router.ts"
  lang="ts"
  code={`import { createRouter, v } from "@epoch32/visage/rpc";

export const appRouter = createRouter()
  .query("getUser", {
    input: v.object({ id: v.string() }),
    resolve: async ({ input }) => ({ id: input.id, name: "Alice" }),
  })
  .mutation("createPost", {
    input: v.object({ title: v.string() }),
    resolve: async ({ input }) => ({ postId: "post-99", title: input.title }),
  });`}
/>

## Server Fetch Handler (createFetchHandler)

Mount the router on standard Web `fetch` standards (Cloudflare Workers, Bun, Node, Deno, Vite dev server):

<CodeBlock
  filename="server/index.ts"
  lang="ts"
  code={`import { createFetchHandler } from "@epoch32/visage/rpc";
import { appRouter } from "./router";

const handler = createFetchHandler({
  router: appRouter,
  endpoint: "/api/rpc",
  cors: {
    origin: "*",
    methods: ["GET", "POST", "OPTIONS"],
  },
});

// Bun / Node / Cloudflare standard export
export default {
  fetch(req: Request) {
    return handler(req);
  },
};`}
/>

## Typed Client & Query Integration (createClient)

Initialize the client with your server's router type:

<CodeBlock
  filename="src/client.ts"
  lang="ts"
  code={`import { createClient } from "@epoch32/visage/rpc";
import type { AppRouter } from "../server/router";

export const rpc = createClient<AppRouter>({
  baseUrl: "/api/rpc",
  headers: () => ({
    Authorization: \`Bearer \${localStorage.getItem("token") ?? ""}\`,
  }),
});`}
/>

### Direct Invocation and Reactive Signals

You can call procedures directly or generate fine-grained Visage query signals:

<CodeBlock
  filename="client-usage.ts"

## Real-Time Streaming Subscriptions

Consume SSE streams with typed event listeners:

<CodeBlock
  filename="TelemetryFeed.tsx"
  lang="tsx"
  code={`import { onCleanup, createSignal } from "@epoch32/visage";
import { rpc } from "./client";

export function LiveMonitor() {
  const [load, setLoad] = createSignal(0);

  const sub = rpc.liveMetrics.subscribe(
    { intervalMs: 1000 },
    {
      onData: (data) => setLoad(Math.round(data.cpu)),
      onError: (err) => console.error("Stream error:", err),
    }
  );

  onCleanup(() => sub.unsubscribe());

  return <div>Current CPU Load: {load}%</div>;
}`}
/>

## Error Handling (RPCError)

Throw `RPCError` on the server to pass typed, structured errors to the client:

<CodeBlock
  filename="server-error.ts"
  lang="ts"
  code={`import { RPCError } from "@epoch32/visage/rpc";

throw new RPCError("NOT_FOUND", "The requested document was not found", { docId: 404 });`}
/>

Available error codes:
- `BAD_REQUEST` (400)
- `UNAUTHORIZED` (401)
- `FORBIDDEN` (403)
- `NOT_FOUND` (404)
- `METHOD_NOT_ALLOWED` (405)
- `TIMEOUT` (408)
- `CONFLICT` (409)
- `INTERNAL_SERVER_ERROR` (500)
