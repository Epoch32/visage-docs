## Compiler Configuration (tsconfig.json)

To configure TypeScript for Visage JSX, set `jsx` to `"preserve"` (or `"react-jsx"`) and point `jsxImportSource` to `@epoch32/visage`:

<CodeBlock
  filename="tsconfig.json"
  lang="json"
  code={`{
  "compilerOptions": {
    "target": "ESNext",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "jsx": "preserve",
    "jsxImportSource": "@epoch32/visage",
    "strict": true,
    "skipLibCheck": true,
    "types": ["vite/client"]
  },
  "include": ["src"]
}`}
/>

<Callout type="tip" title="Automatic JSX Import">
  With <code>"jsxImportSource": "@epoch32/visage"</code>, the TypeScript compiler automatically resolves the Visage JSX factory from <code>@epoch32/visage/jsx-runtime</code>. You never need to import <code>h</code> or <code>jsx</code> manually.
</Callout>

## JSX Runtime & Typing

Visage exports the core `Child` type representing any renderable node:

<CodeBlock
  filename="types.ts"
  lang="ts"
  code={`import type { Child, ReadonlySignal } from "@epoch32/visage";

// Child represents any valid Visage node:
// Node | string | number | boolean | null | undefined | ReadonlySignal<any> | (() => any) | Child[]`}
/>

In Visage JSX, child expressions can be:
- Static primitives: `string`, `number`, `boolean`, `null`, `undefined`
- Native DOM Nodes: `HTMLElement`, `SVGElement`, `DocumentFragment`
- Reactive signals: `ReadonlySignal<T>`
- Reactive accessors: `() => Child`
- Arrays of children: `Child[]`

## Typing Components & Props

Components in Visage are plain TypeScript functions that return a `Child`:

<CodeBlock
  filename="Button.tsx"
  lang="tsx"
  code={`import type { Child } from "@epoch32/visage";

export interface ButtonProps {
  variant?: "primary" | "secondary" | "outline";
  disabled?: boolean;
  onClick?: (e: MouseEvent) => void;
  children?: Child;
}

export function Button(props: ButtonProps): Child {
  const { variant = "primary", disabled = false, onClick, children } = props;

  return (
    <button
      class={\`btn btn-\${variant}\`}
      disabled={disabled}
      onClick={onClick}
    >
      {children}
    </button>
  );
}`}
/>

## Typing Signals & Stores

Signals infer their generic types from initial values, or you can provide explicit type parameters:

<CodeBlock
  filename="state-types.ts"
  lang="ts"
  code={`import { createSignal, createStore, type WritableSignal, type Store } from "@epoch32/visage";

// Inferred as WritableSignal<number>
const [count, setCount] = createSignal(0);

// Explicit type union with null
interface User {
  id: string;
  name: string;
  email: string;
}

const [currentUser, setCurrentUser] = createSignal<User | null>(null);

// Deep reactive stores
interface AppSettings {
  theme: "light" | "dark" | "system";
  notifications: {
    email: boolean;
    push: boolean;
  };
}

const [settings, setSettings] = createStore<AppSettings>({
  theme: "system",
  notifications: {
    email: true,
    push: false,
  },
});`}
/>

## DOM References (Refs)

Visage supports callback refs that pass the mounted DOM element directly to your function:

<CodeBlock
  filename="RefExample.tsx"
  lang="tsx"
  code={`import type { Child } from "@epoch32/visage";

export function AutoFocusInput(): Child {
  let inputRef: HTMLInputElement | null = null;

  return (
    <input
      ref={(el: HTMLElement | null) => {
        inputRef = el as HTMLInputElement | null;
        if (inputRef) {
          inputRef.focus();
        }
      }}
      type="text"
      placeholder="Type here..."
    />
  );
}`}
/>
