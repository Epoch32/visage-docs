Visage IO (`visage/io`) provides headless, fine-grained reactive primitives for drag-and-drop file ingestion, file dialog triggers, object URL lifecycle cleanup, and reactive clipboard read/write with legacy fallbacks.

<FeatureGrid>
  <FeatureCard icon="folder" title="Zero-Flicker Drag Counter">
    Tracks nested DOM enter/leave cycles using an internal counter, avoiding erratic drag-leave flicker when hovering over child elements.
  </FeatureCard>

  <FeatureCard icon="shield-check" title="Strict MIME & Extension Filters">
    Supports exact MIME types (<code>image/png</code>), wildcards (<code>image/*</code>), file extensions (<code>.pdf</code>), and size caps with detailed rejection reasons.
  </FeatureCard>
</FeatureGrid>

## Drag and Drop DropZone (&lt;DropZone&gt; / createDropZone)

Use the headless `<DropZone>` component with render props or the lower-level `createDropZone` primitive:

<CodeBlock
  filename="DropZoneExample.tsx"
  lang="tsx"
  code={`import { DropZone, createSignal, For } from "@epoch32/visage";

export function FileUploader() {
  const [files, setFiles] = createSignal<File[]>([]);
  const [errors, setErrors] = createSignal<string[]>([]);

  return (
    <div>
      <DropZone
        accept={["image/*", ".pdf"]}
        maxSize={10 * 1024 * 1024} // 10MB
        maxFiles={5}
        onDrop={(accepted, rejections) => {
          setFiles((prev) => [...prev, ...accepted]);
          if (rejections.length > 0) {
            setErrors(rejections.map((r) => \`\${r.file.name}: \${r.reason}\`));
          }
        }}
      >
        {({ isDraggingOver, openPicker }) => (
          <div
            onClick={openPicker}
            class="dropzone-box"
            data-drag-over={isDraggingOver()}
            style={{
              padding: "32px",
              border: "2px dashed var(--border)",
              borderRadius: "8px",
              textAlign: "center",
              cursor: "pointer",
              background: () => (isDraggingOver() ? "var(--accent-subtle)" : "var(--bg)"),
            }}
          >
            <p>
              {() =>
                isDraggingOver()
                  ? "Drop files right here..."
                  : "Drag files here, or click to browse"
              }
            </p>
          </div>
        )}
      </DropZone>

      <Show when={() => files().length > 0}>
        <ul>
          <For each={files}>
            {(file) => <li>{file.name} ({(file.size / 1024).toFixed(1)} KB)</li>}
          </For>
        </ul>
      </Show>
    </div>
  );
}`}
/>

### Lower-Level `createDropZone` Primitive

Bind directly to an existing DOM container ref:

<CodeBlock
  filename="createDropZoneExample.ts"
  lang="ts"
  code={`import { createDropZone } from "@epoch32/visage";

const zone = createDropZone(() => dropTargetRef.current, {
  accept: ["image/png", "image/jpeg"],
  maxSize: 5 * 1024 * 1024,
  onDrop: (accepted, rejections) => {
    console.log("Accepted files:", accepted);
    console.log("Rejected files:", rejections);
  },
});

// zone.isDraggingOver() is a reactive boolean signal`}
/>

## Reactive Clipboard (createClipboard)

Read and write text to the system clipboard with an auto-resetting status signal and legacy `document.execCommand` fallback:

<CodeBlock
  filename="CopyButton.tsx"
  lang="tsx"
  code={`import { createClipboard } from "@epoch32/visage";

export function CopySnippet({ code }: { code: string }) {
  const clipboard = createClipboard({ timeout: 2000 });

  return (
    <button
      type="button"
      onClick={() => clipboard.copy(code)}
      class="btn"
    >
      {() => (clipboard.copied() ? "Copied to clipboard!" : "Copy code")}
    </button>
  );
}`}
/>

## Imperative File Picker (createFilePicker)

Open a native file selection dialog imperatively without leaving permanent `<input type="file">` nodes in your DOM:

<CodeBlock
  filename="filePickerExample.ts"
  lang="ts"
  code={`import { createFilePicker } from "@epoch32/visage";

const picker = createFilePicker({
  accept: [".json", ".csv"],
  multiple: true,
  onFiles: (files) => {
    console.log("Selected files:", files);
  },
});

// Trigger file picker dialog on demand:
picker.open();`}
/>

## Object URL Management (createMediaUrl)

Create temporary blob/media preview URLs that automatically call `URL.revokeObjectURL` when the reactive scope or component unmounts:

<CodeBlock
  filename="MediaPreview.tsx"
  lang="tsx"
  code={`import { createMediaUrl } from "@epoch32/visage";

export function ImagePreview({ file }: { file: File }) {
  // Automatically revokes URL on unmount to prevent browser memory leaks
  const previewUrl = createMediaUrl(() => file);

  return <img src={previewUrl()} alt="Preview" style={{ maxWidth: "200px" }} />;
}`}
/>

## Paste Event Handler (onPaste)

Extract pasted files and text cleanly from container elements or the global window:

<CodeBlock
  filename="PasteArea.tsx"
  lang="tsx"
  code={`import { onPaste } from "@epoch32/visage";

const cleanup = onPaste({
  target: () => document.body,
  onFiles: (files) => {
    console.log("Pasted files:", files);
  },
  onText: (text) => {
    console.log("Pasted text:", text);
  },
});`}
/>
