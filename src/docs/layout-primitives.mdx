## Vertical Stack (&lt;Stack&gt;)

`<Stack>` organizes children into a vertical column with predictable gap spacing:

<CodeBlock
  filename="StackExample.tsx"
  lang="tsx"
  code={`import { Stack } from "@epoch32/visage";

export function ProfileCard() {
  return (
    <Stack gap={3} p={4} style={{ border: "1px solid var(--border)", borderRadius: "8px" }}>
      <h3>User Profile</h3>
      <p>Configure your workspace notifications and team access.</p>
      <button class="btn">Update Preferences</button>
    </Stack>
  );
}`}
/>

Props:
- `gap`: Spacing between children (e.g. `3` = `12px`).
- `align`: Flex cross-axis alignment (`"start" | "center" | "end" | "stretch" | "baseline"`).
- `justify`: Main-axis distribution (`"start" | "center" | "end" | "between" | "around" | "evenly"`).
- `reversed`: Renders in reverse column order (`column-reverse`).

## Horizontal Row (&lt;Row&gt;)

`<Row>` arranges children horizontally. By default, it centers children vertically (`align="center"`) for natural icon and label alignment:

<CodeBlock
  filename="RowExample.tsx"
  lang="tsx"
  code={`import { Row, Spacer } from "@epoch32/visage";

export function NavigationHeader() {
  return (
    <Row gap={4} px={6} py={3} justify="between">
      <div class="logo">Visage</div>

      <Row gap={3}>
        <a href="#docs">Docs</a>
        <a href="#examples">Examples</a>
        <button class="btn btn-primary">Sign In</button>
      </Row>
    </Row>
  );
}`}
/>

## CSS Grid (&lt;Grid&gt;)

`<Grid>` provides effortless CSS Grid layouts. You can declare fixed columns or use `minChildWidth` for self-responsive fluid wrapping:

<CodeBlock
  filename="GridExample.tsx"
  lang="tsx"
  code={`import { Grid } from "@epoch32/visage";

// 1. Responsive auto-fitting columns (wraps automatically on smaller screens)
export function ProductGrid() {
  return (
    <Grid minChildWidth={280} gap={4}>
      <div class="card">Item 1</div>
      <div class="card">Item 2</div>
      <div class="card">Item 3</div>
      <div class="card">Item 4</div>
    </Grid>
  );
}

// 2. Explicit fixed column repeat
export function StatsDashboard() {
  return (
    <Grid columns={3} gap={4}>
      <div class="stat">Revenue</div>
      <div class="stat">Users</div>
      <div class="stat">Conversion</div>
    </Grid>
  );
}`}
/>

## Centering (&lt;Center&gt;)

`<Center>` aligns children horizontally and vertically without flexbox boilerplate or absolute margin hacks:

<CodeBlock
  filename="CenterExample.tsx"
  lang="tsx"
  code={`import { Center } from "@epoch32/visage";

export function LoadingScreen() {
  return (

}`}
/>

## Elastic Spacers (&lt;Spacer&gt;)

`<Spacer>` expands to fill remaining space in a `<Row>` or `<Stack>` (`flex: 1 1 0%`), pushing neighboring items to opposite edges:

<CodeBlock
  filename="SpacerExample.tsx"
  lang="tsx"
  code={`import { Row, Spacer } from "@epoch32/visage";

export function Toolbar() {
  return (
    <Row p={2}>
      <span>Dashboard / Overview</span>

      {/* Pushes actions to the right edge */}
      <Spacer />

      <button class="btn">Export CSV</button>
      <button class="btn btn-primary">New Project</button>
    </Row>
  );
}`}
/>

Pass `size={4}` to `<Spacer>` to render a fixed-dimension spacer block instead of an expanding flex item.

## API Reference

### `<Stack>`

Vertical flex column container enforcing consistent gap spacing and zero margin collapse.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Stack(props: {
  gap?: number | string;
  align?: "start" | "center" | "end" | "stretch" | "baseline";
  justify?: "start" | "center" | "end" | "between" | "around" | "evenly";
  as?: string;
  children?: Element | Element[];
}): Element`}
/>

#### Props
- `gap` (`number | string`, optional): Spacing between items mapped to the 4px spatial scale.
- `align` (`"start" | "center" | "end" | "stretch" | "baseline"`, optional): Cross-axis flex item alignment.
- `justify` (`string`, optional): Main-axis flex distribution.
- `as` (`string`, optional): HTML tag to render. Defaults to `"div"`.

### `<Row>`

Horizontal flex row with default vertical centering (`align="center"`).

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Row(props: {
  gap?: number | string;
  align?: "start" | "center" | "end" | "stretch" | "baseline";
  justify?: "start" | "center" | "end" | "between" | "around" | "evenly";
  wrap?: boolean;
  as?: string;
  children?: Element | Element[];
}): Element`}
/>

#### Props
- `gap` (`number | string`, optional): Spacing between items.
- `align` (`string`, optional): Cross-axis alignment. Defaults to `"center"`.
- `justify` (`string`, optional): Main-axis distribution.
- `wrap` (`boolean`, optional): Whether flex items wrap onto multiple lines.

<hr className="api-divider" />

### `<Grid>`

CSS Grid primitive supporting fixed column counts or responsive self-wrapping `minChildWidth`.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Grid(props: {
  columns?: number | string;
  minChildWidth?: number | string;
  gap?: number | string;
  as?: string;
  children?: Element | Element[];
}): Element`}
/>

#### Props
- `columns` (`number | string`, optional): Explicit number of columns (e.g. `3` or `"repeat(3, 1fr)"`).
- `minChildWidth` (`number | string`, optional): Responsive min child size triggering `auto-fill`.
- `gap` (`number | string`, optional): Grid gap spacing.

<hr className="api-divider" />

### `<Center>`

Centers child content horizontally and vertically without CSS boilerplate.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Center(props: {
  inline?: boolean;
  as?: string;
  children?: Element | Element[];
}): Element`}
/>

#### Props
- `inline` (`boolean`, optional): When true, renders as an inline-flex element.
- `as` (`string`, optional): Tag name to render. Defaults to `"div"`.

<hr className="api-divider" />

### `<Spacer>`

Expanding flex element (`flex: 1 1 0%`) or fixed dimensional spatial divider block.

<CodeBlock
  lang="tsx"
  filename="signature"
  code={`function Spacer(props: {
  size?: number | string;
  flex?: boolean | number;
}): Element`}
/>

#### Props
- `size` (`number | string`, optional): Explicit width or height dimension.
- `flex` (`boolean | number`, optional): Flex grow/shrink factor. Defaults to `1`.
