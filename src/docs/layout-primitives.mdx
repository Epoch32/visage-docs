Visage provides composable layout primitives that encode spatial consistency directly into JSX. They eliminate margin hacks, flexbox alignment boilerplate, and messy media query breakpoints.

## Vertical Stack (&lt;Stack&gt;)

`<Stack>` organizes children into a vertical column with predictable gap spacing:

<CodeBlock
  filename="StackExample.tsx"
  lang="tsx"
  code={`import { Stack } from "@epoch32/visage";

export function ProfileCard() {
  return (
    <Stack gap={3} p={4} style={{ border: "1px solid var(--border)", borderRadius: "8px" }}>
      <h3>User Profile</h3>
      <p>Configure your workspace notifications and team access.</p>
      <button class="btn">Update Preferences</button>
    </Stack>
  );
}`}
/>

Props:
- `gap`: Spacing between children (e.g. `3` = `12px`).
- `align`: Flex cross-axis alignment (`"start" | "center" | "end" | "stretch" | "baseline"`).
- `justify`: Main-axis distribution (`"start" | "center" | "end" | "between" | "around" | "evenly"`).
- `reversed`: Renders in reverse column order (`column-reverse`).

## Horizontal Row (&lt;Row&gt;)

`<Row>` arranges children horizontally. By default, it centers children vertically (`align="center"`) for natural icon and label alignment:

<CodeBlock
  filename="RowExample.tsx"
  lang="tsx"
  code={`import { Row, Spacer } from "@epoch32/visage";

export function NavigationHeader() {
  return (
    <Row gap={4} px={6} py={3} justify="between">
      <div class="logo">Visage</div>

      <Row gap={3}>
        <a href="#docs">Docs</a>
        <a href="#examples">Examples</a>
        <button class="btn btn-primary">Sign In</button>
      </Row>
    </Row>
  );
}`}
/>

## CSS Grid (&lt;Grid&gt;)

`<Grid>` provides effortless CSS Grid layouts. You can declare fixed columns or use `minChildWidth` for self-responsive fluid wrapping:

<CodeBlock
  filename="GridExample.tsx"
  lang="tsx"
  code={`import { Grid } from "@epoch32/visage";

// 1. Responsive auto-fitting columns (wraps automatically on smaller screens)
export function ProductGrid() {
  return (
    <Grid minChildWidth={280} gap={4}>
      <div class="card">Item 1</div>
      <div class="card">Item 2</div>
      <div class="card">Item 3</div>
      <div class="card">Item 4</div>
    </Grid>
  );
}

// 2. Explicit fixed column repeat
export function StatsDashboard() {
  return (
    <Grid columns={3} gap={4}>
      <div class="stat">Revenue</div>
      <div class="stat">Users</div>
      <div class="stat">Conversion</div>
    </Grid>
  );
}`}
/>

## Centering (&lt;Center&gt;)

`<Center>` aligns children horizontally and vertically without flexbox boilerplate or absolute margin hacks:

<CodeBlock
  filename="CenterExample.tsx"
  lang="tsx"
  code={`import { Center } from "@epoch32/visage";

export function LoadingScreen() {
  return (
    <Center h="screen">
      <div class="spinner">Loading Visage Application...</div>
    </Center>
  );
}`}
/>

## Elastic Spacers (&lt;Spacer&gt;)

`<Spacer>` expands to fill remaining space in a `<Row>` or `<Stack>` (`flex: 1 1 0%`), pushing neighboring items to opposite edges:

<CodeBlock
  filename="SpacerExample.tsx"
  lang="tsx"
  code={`import { Row, Spacer } from "@epoch32/visage";

export function Toolbar() {
  return (
    <Row p={2}>
      <span>Dashboard / Overview</span>

      {/* Pushes actions to the right edge */}
      <Spacer />

      <button class="btn">Export CSV</button>
      <button class="btn btn-primary">New Project</button>
    </Row>
  );
}`}
/>

Pass `size={4}` to `<Spacer>` to render a fixed-dimension spacer block instead of an expanding flex item.
