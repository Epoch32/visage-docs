Visage provides two foundational primitives for orchestrating DOM boundaries and asynchronous execution: `<Portal>` for escaping parent overflow containers into external DOM nodes, and `<Suspense>` for coordinating async data loading.

<FeatureGrid>
  <FeatureCard icon="external-link" title="Context-Preserving Portals">
    <code>&lt;Portal&gt;</code> teleports DOM nodes into <code>document.body</code> or any target element while completely preserving signal ownership and Context scopes.
  </FeatureCard>

  <FeatureCard icon="hourglass" title="Fine-Grained Suspense">
    <code>&lt;Suspense&gt;</code> automatically tracks pending promises registered by <code>createResource</code>, <code>lazy</code>, or <code>createQuery</code> without tearing down parent trees.
  </FeatureCard>
</FeatureGrid>

## Portals (&lt;Portal&gt;)

Modals, tooltips, dialogs, and dropdowns frequently need to render outside their parent DOM hierarchy to avoid `overflow: hidden`, `z-index`, or CSS `transform` clipping.

The `<Portal>` component mounts its children into `document.body` by default while maintaining reactive scope linkage:

<CodeBlock
  filename="ModalPortal.tsx"
  lang="tsx"
  code={`import { Portal, createSignal, Show } from "@epoch32/visage";

function ModalExample() {
  const [isOpen, setIsOpen] = createSignal(false);

  return (
    <div>
      <button onClick={() => setIsOpen(true)}>Open Modal</button>

      <Show when={isOpen}>
        <Portal>
          <div class="modal-backdrop" onClick={() => setIsOpen(false)}>
            <div class="modal-card" onClick={(e) => e.stopPropagation()}>
              <h2>Teleported Dialog</h2>
              <p>Rendered at the root of document.body with zero CSS clipping!</p>
              <button onClick={() => setIsOpen(false)}>Close</button>
            </div>
          </div>
        </Portal>
      </Show>
    </div>
  );
}`}
/>

## Custom Mount Targets

Pass a target element to the `mount` prop to render into a specific DOM container instead of `document.body`:

<CodeBlock
  filename="CustomMount.tsx"
  lang="tsx"
  code={`import { Portal } from "@epoch32/visage";

function NotificationLayer() {
  const container = document.getElementById("toast-container");

  return (
    <Portal mount={container}>
      <div class="notification-toast">
        System update completed.
      </div>
    </Portal>
  );
}`}
/>

## Async Suspense (&lt;Suspense&gt;)

`<Suspense>` displays a `fallback` UI while child async resources, queries, or lazy-loaded components are pending:

<CodeBlock
  filename="SuspenseExample.tsx"
  lang="tsx"
  code={`import { Suspense } from "@epoch32/visage";
import { UserProfile } from "./UserProfile";

function Dashboard() {
  return (
    <div class="dashboard-layout">
      <h1>Account Overview</h1>

      <Suspense fallback={<div class="skeleton-loader">Loading profile...</div>}>
        <UserProfile />
      </Suspense>
    </div>
  );
}`}
/>

## Async State (createResource)

Visage's `createResource` coordinates directly with `<Suspense>`. When a resource fetch initiates, it registers the promise with the surrounding Suspense context:

<CodeBlock
  filename="UserProfile.tsx"
  lang="tsx"
  code={`import { createResource } from "@epoch32/visage";

async function fetchUser(): Promise<{ name: string; email: string }> {
  const res = await fetch("/api/user");
  return res.json();
}

export function UserProfile() {
  const [user, { refetch }] = createResource(fetchUser);

  return (
    <div class="user-card">
      <h3>{() => user()?.name}</h3>
      <p>{() => user()?.email}</p>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}`}
/>

## Lazy Code Splitting (lazy)

Use `lazy()` to dynamically import heavy components on demand. Visage coordinates the module download with `<Suspense>`:

<CodeBlock
  filename="LazyRoutes.tsx"
  lang="tsx"
  code={`import { lazy, Suspense } from "@epoch32/visage";

// Component is downloaded only when rendered
const HeavyAnalyticsChart = lazy(() => import("./AnalyticsChart"));

export function AnalyticsPage() {
  return (
    <section>
      <h2>Performance Metrics</h2>

      <Suspense fallback={<div>Loading interactive chart...</div>}>
        <HeavyAnalyticsChart />
      </Suspense>
    </section>
  );
}`}
/>
