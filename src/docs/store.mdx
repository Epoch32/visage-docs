## How Stores Work: Proxy Architecture

In traditional frameworks, updating a deeply nested object requires creating copies of every parent object along the tree:

<CodeBlock
  filename="comparison.ts"
  lang="ts"
  code={`// The React / Immutable way (spread copies every level):
setUser(prev => ({
  ...prev,
  profile: {
    ...prev.profile,
    address: {
      ...prev.profile.address,
      city: "Austin"
    }
  }
}));

// The Visage way (direct mutation with surgical proxy interception):
user.profile.address.city = "Austin";`}
/>

Visage achieves this through a lazy proxy system:

- **Lazy Proxy Wrapping:** Nested objects are not wrapped up front; they are wrapped on demand as you traverse properties.
- **Property-Level Signals:** When a property like `store.user.name` is read inside a computation or JSX expression, Visage generates an internal atomic signal for that specific property key and registers the subscription.
- **Deduplicated Writes:** If you assign an identical value (`store.user.name = store.user.name`), Visage uses `Object.is` equality to prevent redundant downstream notifications.

## Direct Mutation & Arrays

Visage stores seamlessly support standard JavaScript array mutation methods. Mutating an array automatically updates both individual index subscribers and length subscribers:

<CodeBlock
  filename="arrays.ts"
  lang="ts"
  code={`import { createStore } from "@epoch32/visage";

const store = createStore({
  todos: [
    { id: 1, title: "Build fine-grained UI", done: true },
    { id: 2, title: "Deploy to Cloudflare", done: false }
  ]
});

// Mutate items directly:
store.todos[1].done = true;

// Standard array methods work automatically:
store.todos.push({ id: 3, title: "Write documentation", done: false });
store.todos.splice(0, 1);`}
/>

## Batched Updates with mutateStore

When performing multiple related mutations at once, use `mutateStore`. It wraps all mutations in a synchronous `batch()`, ensuring effects and subscribers only notify once after all mutations complete:

<CodeBlock
  filename="batched-mutation.ts"
  lang="ts"
  code={`import { createStore, mutateStore } from "@epoch32/visage";

const store = createStore({
  counter: 0,
  step: 1,
  status: "idle"
});

// All mutations inside the callback run in a single atomic batch:
mutateStore(store, (draft) => {
  draft.counter += 10;
  draft.step = 5;
  draft.status = "updated";
});`}
/>

## Unwrapping Raw Objects

Sometimes you need to pass a clean, un-proxied JavaScript object to an external library, web worker, or serialization pipeline. Use `unwrapStore` to retrieve the raw underlying object:

<CodeBlock
  filename="unwrap.ts"
  lang="ts"
  code={`import { createStore, unwrapStore } from "@epoch32/visage";

const store = createStore({
  config: { theme: "dark", retries: 3 }
});

// Returns the underlying plain JavaScript object without proxy traps:
const rawObject = unwrapStore(store);

// Ideal for structured cloning or posting to Web Workers:
window.postMessage(unwrapStore(store.config), "*");`}
/>
