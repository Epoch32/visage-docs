# Contributing to Visage Documentation

Thank you for your interest in improving the Visage documentation! Clear, accurate, and concise documentation is essential for the Visage developer experience.

## How to Contribute

1. **Fork and clone** the repository:
   ```bash
   git clone https://github.com/Epoch32/visage-docs.git
   cd visage-docs
   ```

2. **Install dependencies**:
   ```bash
   bun install
   ```

3. **Create a branch**:
   ```bash
   git checkout -b docs/your-topic-name
   ```

4. **Make your changes**:
   - Keep explanations clear, concise, and technically accurate.
   - Ensure all code snippets and interactive examples run without errors.
   - Test your changes locally using `bun run dev`.

5. **Submit a Pull Request**:
   - Open a detailed PR describing the improvements made.
   - Include references or screenshots for new or updated documentation pages.

## Style Guidelines

- **Clarity over cleverness**: Write direct, easy-to-follow explanations.
- **Tone**: Keep documentation professional, welcoming, and focused on developer productivity.
