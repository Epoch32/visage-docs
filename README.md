# Visage Documentation

Official documentation website, interactive API references, and guides for [Visage](https://github.com/Epoch32/visage).

## Overview

This repository houses the source code, content, and interactive examples for the Visage documentation platform.

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) (v1.1+ recommended) or Node.js (v20+)

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Epoch32/visage-docs.git
cd visage-docs
bun install
```

### Local Development

Start the local development server:

```bash
bun run dev
```

### Production Build

Build the documentation site for production:

```bash
bun run build
```

Preview the production build locally:

```bash
bun run preview
```
